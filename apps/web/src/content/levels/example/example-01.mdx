## Tujuan

Arahkan program ke fungsi `win`, yaitu fungsi yang mencetak pesan `WIN` sebagai tanda berhasil. Anda akan melakukannya dengan mengganti alamat kembali program melalui data masukan.

Ini level contoh terpandu. Payload lengkap sudah tersedia di workspace agar Anda bisa mempelajari bagian-bagiannya sebelum mencoba perubahan sendiri.

## Kenali istilahnya

- **Payload**: data masukan yang Anda susun untuk mengubah perilaku program.
- **Buffer**: ruang penampung masukan. Pada contoh ini kapasitasnya 64 byte.
- **Stack**: bagian memori untuk data sementara ketika fungsi berjalan.
- **Saved EBP**: nilai penunjuk stack fungsi pemanggil yang disimpan, sepanjang 4 byte pada contoh ini.
- **Return address (alamat kembali)**: alamat instruksi yang dituju setelah fungsi selesai. Inilah bagian yang akan Anda ganti dengan alamat `win`.
- **`p32`**: pembantu untuk mengubah angka menjadi 4 byte dalam urutan little-endian, yaitu byte bernilai paling rendah ditulis lebih dahulu.

## Ikuti empat langkah

1. **Pahami.** Baca tab **Kode sumber**. Fungsi `vuln` menyediakan buffer 64 byte, tetapi menerima hingga 256 byte. Masukan yang terlalu panjang bisa menimpa data setelah buffer.
2. **Susun.** Pelajari contoh `"A" * 68 + p32(0x0804802d)`. Sebanyak 68 byte mengisi buffer dan saved EBP. Empat byte berikutnya mengganti alamat kembali dengan alamat `win`. Angka ini khusus untuk contoh ini.
3. **Uji.** Pilih **Uji payload**. Periksa apakah program mencapai `win` dan mencetak `WIN`. Anda juga boleh mencoba masukan lebih pendek untuk membandingkan hasilnya.
4. **Kirim.** Setelah uji berhasil, pilih **Kirim jawaban**. Masuk dengan GitHub bila diminta, lalu uji ulang setelah kembali. Server memeriksa jawaban sebelum menyimpan poin dan membuka tautan level berikutnya.

Butuh bantuan? Pilih **Lihat petunjuk** di workspace. Tab instruksi mesin, memori stack, dan register tersedia untuk mengenal detail teknis; Anda bisa memulai dari kode sumber terlebih dahulu.
