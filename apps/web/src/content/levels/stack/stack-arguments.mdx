## Tujuan

Bangun stack panggilan fungsi dengan dua argumen yang benar.

## Konsep

Dalam konvensi panggilan **cdecl x86-32**, argumen diletakkan di stack. Pada saat fungsi baru dimasuki, `[ESP]` berisi alamat kembali, `[ESP+4]` argumen pertama, dan `[ESP+8]` argumen kedua.

Ketika masuk melalui `ret`, prosesor tidak melakukan `call` baru. Anda perlu menyusun sendiri stack yang menyerupai hasil pemanggilan fungsi: alamat kembali pengganti disusul argumen-argumen. Urutan ini berbeda dari sekadar menambahkan argumen tepat setelah pengisi.

## Panduan alat

Cari alamat `win` pada disassembly dan hitung offset berdasarkan buffer soal ini. Baca dua pemeriksaan di representasi C: argumen pertama harus `0x13579bdf`, argumen kedua `0x2468ace0`.

Jika output belum sesuai, periksa memori sesudah lokasi return address. Pastikan setiap bagian memakai empat byte. Fungsi `win` mengakhiri program dengan `exit`, sehingga slot alamat kembali pengganti tetap harus ada meskipun tidak akan dijalankan.

## Tantangan

Arahkan eksekusi ke `win` dengan kedua argumen benar sampai program mencetak `STACK_ARGUMENTS_OK`. Program yang mencapai fungsi dengan argumen salah akan keluar tanpa penanda sukses.
